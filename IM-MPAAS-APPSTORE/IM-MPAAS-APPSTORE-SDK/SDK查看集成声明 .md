# AAR 文件说明

合并后的 AAR 文件（IM + AppStore 单包）直接存放在本仓库中。

**查看地址：** [https://github.com/OortCloudGroup/Wroukup-SDK/blob/main/IM-MPAAS-APPSTORE/IM-MPAAS-APPSTORE-SDK/im-mpaas-appstore-release.aar](https://github.com/OortCloudGroup/Wroukup-SDK/blob/main/IM-MPAAS-APPSTORE/IM-MPAAS-APPSTORE-SDK/im-mpaas-appstore-release.aar)

**直接下载：** [https://raw.githubusercontent.com/OortCloudGroup/Wroukup-SDK/main/IM-MPAAS-APPSTORE/IM-MPAAS-APPSTORE-SDK/im-mpaas-appstore-release.aar](https://raw.githubusercontent.com/OortCloudGroup/Wroukup-SDK/main/IM-MPAAS-APPSTORE/IM-MPAAS-APPSTORE-SDK/im-mpaas-appstore-release.aar)

下载后将 AAR 文件放置到项目对应的 `libs` 目录中即可。

或者您也可以直接使用远程依赖方式引入，无需手动下载 AAR 文件。
