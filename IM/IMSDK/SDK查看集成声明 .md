# AAR 文件说明

AAR 文件直接存放在本仓库中。

**查看地址：** [https://github.com/OortCloudGroup/Wroukup-SDK/blob/main/IM/IMSDK/im-release.aar](https://github.com/OortCloudGroup/Wroukup-SDK/blob/main/IM/IMSDK/im-release.aar)

**直接下载：** [https://raw.githubusercontent.com/OortCloudGroup/Wroukup-SDK/main/IM/IMSDK/im-release.aar](https://raw.githubusercontent.com/OortCloudGroup/Wroukup-SDK/main/IM/IMSDK/im-release.aar)

下载后将 AAR 文件放置到项目对应的 `libs` 目录中即可。

或者您也可以直接使用远程依赖方式引入，无需手动下载 AAR 文件。
